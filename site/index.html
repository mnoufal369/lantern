Security first

Locked down like it should be

Pilot is built on the principle that an AI with your keyboard deserves a seatbelt.

🔐

Keys encrypted in your keychain

API keys are encrypted at rest with macOS keychain-backed storage, and never leave the app's core process — the UI literally cannot read them.

🏠

100% local, zero telemetry

Sessions, transcripts and profiles live only on your machine. No analytics, no tracking, no third-party servers. The only network traffic is the agent talking to Anthropic.

🧱

Sandboxed by architecture

The interface runs fully sandboxed with no file or network access, behind a strict content-security policy and a typed, enumerated bridge.

✋

Human in the loop, always

Unattended permission requests fail closed after 5 minutes. Full-auto mode is opt-in, visibly flagged red, and one click away from off.

FAQ

Questions, answered

Do I need to know how to code?

No. Describe what you want in plain language; the agent writes the code and shows you everything it changes. Developers get power tools; everyone else gets a builder that explains itself.

How does it connect to Claude?

Three ways, automatically: an API key you save in Settings (encrypted), an ANTHROPIC_API_KEY in your environment, or your existing Claude Code login on the machine. Settings shows exactly which one is active.

Does the Windows version do everything the Mac version does?

Yes — same engine, same features: agents, personas, repo sessions with branch switching, permission control, exports. It's the identical app built for Windows x64.

I'm in QA or consulting — do I need a dev environment?

No. Install Pilot, paste the repository link (and the branch you're testing), and ask. Pilot fetches the code into its own workspace — no Docker, no local build, no IDE. Generate test cases or client-ready summaries and export them as reports. The only requirement is Git installed on the machine.

What does AI usage cost?

Usage bills to your Claude login or the company API key — Pilot adds nothing on top and shows live per-turn costs. Budget caps per agent are built in.

Can it break my project?

It asks before changing files (unless you opt into auto mode), every change is visible as a diff, and the git panel reverts any file with one click. Work on a branch for extra comfort.

Is my code sent anywhere?

*Only what the agent needs goes to Anthropic's API to generate responses — the same as Claude Code in your terminal. Pilot itself has no servers, no telemetry, and stores everything locally.
